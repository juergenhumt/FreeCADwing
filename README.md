

FreeCADwing is a sequence of macros for FreeCAD that allow you to generate a tapered wing, the wing ribs and place the ribs in a drawing which you can export as an svg file to create e.g. the input for a laser cutter. In this version, v2.0.0, the ribs are cut for the main spar and to accomodate the aileron or a control flap, if you build a mono wing. The problem here was that cutting the common sections, which are generated in the second step by FreeCadWingMkRib could not be cut twice, they were deleted from the file. Therefore each rib is now extruded into a solid and this solid is then cut, which works qite nicely. The new macro name FreeCadWingCutSld reflects the fact, that now solids are used.


The program files are in a directory FreeCADwing, there ar two sub directories called data and ex2. The data subdirectory is used to exchange information between the the different parts of the program. It contains a binary file that stores the path of the current work directory and the current project name. ex1 is the work directory for the test case, you add other project sub directories for yor own projects. The program uses a routing from the library wngUtil.py. Such a library file is usually (on a linux system) located in your home directory in the sub directory 

~/.local/share/FreeCAD/macro

Make shure that the file is placed there so that it can be found by the macros.

FreeCADwing was tested using FreeCAD version 1.0.0

A)    Run the Test
To create the wing for the test case where the project name is MonoWingMk2
- Start FreeCAD and load FreeCadWingStart.FCMacro, and run it
- FreeCadWingStart.FCMacro -> generates the two wing sections and lofts the profiles.
  The profile contours for the inner and outer section are read from a standard format
  *.dat file. A profile is placed at the start and a the end of each section, then the
  profiles are connected by a loft. At the point where the sections meet two identical
  profiles are created to give a continous contour.
  On my computer it took abour 2 to 3 minutes to generate the wing loft. If you delete
  it though and rerun it only takes a few seconds to generate the loft. I have no idea 
  why that is. Next run:
- FreeCadMkRib.FCMacro     -> generates the ribs by cutting the loft. 
  Note that the ribs are placed in between the profiles at the start and end of each
  wing section. This macro replaces the file generated by the previous step so if you
  want to try different rib spacings place a comment in front of the doc.save() command
  at the end of the macro. 
- FreeCadMkCutSld.FCMacro  -> creates the cuts in the wing for the main spar and the
  aileron.
- FreeCadPrn.FCMacro -> generates a plot of all wing ribs and saves the plot as an svg file.
  Note that printing the ribs takes a lot of manual tweaking, so start printing only after
  you feel that your design is mostly right. It is possible to move the individual views
  around on the print page, so it is sufficient to have them roughly at the right place


B)    Use FreeCADwing for your own projects
First define the wing geometry as in file wDat19928.lis (filename is, of course, arbitrary), it contains the data for both inner and outer wing section. Line 0, the first line, is currently not used. Outer wing data start in line 8, after the first nRig.

Next select wing profiles. Note that the profile contour must be closed, thus the value in the first data line (usually 1.000   0.000) must be the same as in the last data line

If the test case has generated the file MonoWingMk2.FCStd and the
svg file 
the sequence to generate a wing and a drawing is:
- create a new sub directory for your project.
- place the profile data files and the wing geometry data file there. 
  Give the data file a name of your choice
- modify the project name and the path to your work directory in the macro 
  FreeCadWingStart.FCMacro. This information will be stored in the data 
  subdirectory in the binary file projData.lis and will be used by the 
  other modules.
- define the wing geometry in the wing geometry file, which, for the test case, 
  is called wDat19928.lis, then run
- FreeCadWingStart.FCMacro -> generates the two wing sections and lofts the profiles, now run
- FreeCadMkRib.FCMacro     -> generates the ribs 
- next you have to create a list that determines which rib is printed and which one is not 
  and it also determines the sequence of the ribs. This step is required since the ribs 
  are not generated continuously from root to tip but in two steps. Step one generates the
  start and end rib of each wing section, step two generates the ribs in between the end
  ribs of each section. Note that during those steps the designations also change. To
  create the print list use the mouse to click on the ribs from start to end and observe
  which entity in the model tree is highlighted by the blue bar. Write the number of this 
  entity to the print list.
- now run FreeCadWingPrnSld.FCMacro, this will generate a page containing all ribs that 
  had a number assigned to them in the in the nObjList (line 66 in the print macro). 
  You can export this page to an svg file. If you want to use it as input to e.g. a
  laser cutter you have to set the line colour manually to rgb [255,0,0] which can be
  done in the print preferences. The spacing of the ribs is tweaked very heavily in the
  print macro but you can adjust the ribs in the output page manually at any time, to
  have them spaced as conviniently for cutting as you wish.
